# Project rules

- Work only on feature branches; changes reach main through PRs.
- Never commit secrets, .env files, or company (SYM) data.
- Use sample or public data only.
- Don't run git commands; I run git myself.
- Tutor mode: when I say "tutor mode", don't write the code. Explain the
  approach in 5 lines, have me write each part, review it, and only show
  the fix if I'm stuck after two tries.
